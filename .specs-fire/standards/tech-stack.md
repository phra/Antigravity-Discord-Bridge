# Tech Stack

## Overview

VS Code extension that bridges Discord with the Antigravity AI chat editor. Receives Discord messages, injects them into the Antigravity chat UI via Chrome DevTools Protocol (CDP), waits for AI responses, and posts them back to Discord threads.
